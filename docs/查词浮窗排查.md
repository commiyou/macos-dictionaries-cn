# 三指查词浮窗完全排查指南

这份文档专门解决：**三指轻点 / 右键查询时，浮窗只显示词头和一个「更多」链接。**

---

## 一、先确认这是哪种情况

在词典.app 里直接搜索同一个词：

- **词典.app 里显示完整** → 词条没问题，问题在浮窗渲染 → 看第二节
- **词典.app 里也不显示** → 安装/索引问题 → 看第四节

---

## 二、浮窗正常工作的三个必要条件

### 条件 1：至少勾选一本系统自带词典 ⚠️ 最常被忽略

macOS 的查词浮窗走系统词典链路。**如果只勾选第三方词典、把所有系统词典取消勾选，浮窗拿不到内容，只显示词头 + 「更多」。**

```
词典.app → 设置（⌘,）
  ☑ 你的第三方词典          ← 排最前
  ☑ 简体中文–英语（系统）    ← 必须至少有一本
```

已验证：取消全部系统词典后，浮窗立刻退化为「更多」；重新勾选后恢复正常。

**这不是词典本身的缺陷**，任何第三方 .dictionary 都受此限制。

### 条件 2：词条不能太长

浮窗高度固定。作为一个可对照的基准：

| 词典 | 单条 `<p>` 数量 | 单条长度 |
|---|---|---|
| Apple Dictionary（系统） | 1 | 300–700 字符 |
| New Oxford American Dictionary | 多个 | 视词而定 |

**建议**：单条控制在 1 个 `<p>`、500 字符以内。次要内容用 `<br/>` 折行或限流。

压缩示例：

```xml
<!-- 太长，浮窗会折叠 -->
<d:entry id="x" d:title="telephone">
  <h1>telephone</h1>
  <div class="head"><span class="phon">/ˈtelɪfəʊn/</span><span class="freq">词频 #1988</span></div>
  <div class="split">…</div>
  <div class="trans"><p>n. 电话</p><p>v. 打电话</p></div>
  <div class="def"><p>…50 条英文释义…</p></div>
  <div class="family"><p>…40 个同根词…</p></div>
</d:entry>

<!-- 精简，浮窗直接显示 -->
<d:entry id="x" d:title="telephone">
  <d:index d:value="telephone" d:title="telephone"/>
  <h1>telephone</h1>
  <p>tele（词根：远；电信） ＋ phon（词根：声音）<br/>n. 电话, 电话机 / v. 打电话<br/>同根词: phonetics, saxophone, megaphone</p>
</d:entry>
```

### 条件 3：`DCSElementXPath` 指向存在的元素

```xml
<key>DCSElementXPath</key>
<dict>
    <key>definitions</key>
    <string>//p</string>
</dict>
```

- 系统词典 Apple Dictionary 用 `//p`（取正文段落）
- 若指向不存在的 class，浮窗可能取不到内容

**先试最简单的 `//p`**，确认能出内容后，再换成更精确的表达式。

## 三、CSS 能做什么、不能做什么

### 能做

浮窗渲染时根元素带 `apple_client-panel` 类，可以只对浮窗收窄排版：

```css
html.apple_client-panel body {
    margin: 0 !important;
    padding: 2px 6px !important;
    line-height: 120% !important;
}
html.apple_client-panel h1 {
    font-size: 100% !important;
    margin: 0 0 0.15em 0 !important;
    border-bottom: none !important;
}
html.apple_client-panel .secondary { display: none !important; }
```

系统词典 `AppleDictionary.css` 里的原始写法可作对照：

```css
html.apple_client-panel body { line-height: 120%; }
html.apple_client-panel h1 { font-size: 100%; margin-block-start: 0em; margin-block-end: 0.2em; }
html.apple_client-panel p { margin-block-start: 0.2em; margin-inline-start: 1.0em; }
```

### 不能做

- ❌ 不能靠 CSS 修复「未勾选系统词典」的问题
- ❌ 不能突破浮窗的固定高度上限
- ❌ 不能改变浮窗本身的尺寸

如果压了 CSS 还是折叠，说明内容本身太长，回到条件 2。

## 四、词典完全不出内容

### 4.1 检查是否被激活

```bash
defaults read com.apple.DictionaryServices DCSActiveDictionaries
```

确认你的 `.dictionary` 路径在列表里。不在的话：词典.app 设置里勾选它。

### 4.2 检查包结构

```bash
ls ~/Library/Dictionaries/我的词典.dictionary/Contents/Resources/
```

应当包含：

```
Body.data  EntryID.data  EntryID.index  KeyText.data  KeyText.index  DefaultStyle.css
```

缺 `KeyText.index` 说明构建失败或被截断。

### 4.3 检查 Info.plist

```bash
plutil -p ~/Library/Dictionaries/我的词典.dictionary/Contents/Info.plist
```

确认：

- `DCSDictionaryCSS` 指向的文件**确实存在**于 `Contents/Resources/`
- **没有** `DCSDictionaryXSL`（除非真放了该文件）
- `CFBundleIdentifier` 唯一

### 4.4 强制重载

```bash
killall Dictionary 2>/dev/null
killall com.apple.DictionaryServiceHelper 2>/dev/null
rm -rf ~/Library/Containers/com.apple.Dictionary/Data/Library/Caches/com.apple.DictionaryApp/*
touch ~/Library/Dictionaries
open -a Dictionary
```

### 4.5 一个已知的系统限制

macOS 26 起，`DCSDictionaryCreate` 这类私有 API 只接受系统 Asset 管理的词典，直接对用户目录下的 `.dictionary` 调用会返回 `nil`。**但这不影响词典.app 界面加载**——界面走的是另一条路径。

所以：**以词典.app 界面实际行为为准**，不要用私有 API 的返回值判断词典是否可用。

## 五、构建期常见报错

| 报错 | 原因 | 修复 |
|---|---|---|
| `Duplicate entry_id: [xxx]` | `d:entry/@id` 重复 | 生成 id 时用集合去重，重复加 `_2` `_3` |
| `PCDATA invalid Char value 11` | XML 混入控制字符 | 转义前过滤 `[\x00-\x08\x0b\x0c\x0e-\x1f]` |
| `Opening and ending tag mismatch` | 文本未转义（含 `<` `>` `&`） | 所有文本走转义函数 |
| `No reference index record` | 没有交叉引用 | 提示，可忽略 |
| `Duplicate index. Skipped` | 归一化后索引重复（如 `suf` 与 `suf-`） | 提示，可忽略 |

### 转义函数参考

```python
import re
_ILLEGAL = re.compile("[\x00-\x08\x0b\x0c\x0e-\x1f\x7f-\x9f\ud800-\udfff\ufffe\uffff]")

def esc(t):
    if t is None: return ""
    t = str(t)
    t = _ILLEGAL.sub(" ", t)
    return (t.replace("&", "&amp;").replace("<", "&lt;")
             .replace(">", "&gt;").replace('"', "&quot;"))
```

## 六、要不要用 Dictionary Development Kit 之外的路子

| 方案 | 适用 |
|---|---|
| **Dictionary Development Kit** | 自己造词库、MDX 转换 —— 唯一能产出 `.dictionary` 的正规途径 |
| **pyglossary** | 解包 `.mdx`（MDict）→ 文本/StarDict，再喂给上面的工具链 |
| **GoldenDict / 欧路 / Easydict** | 不想转换，直接读 MDX/MDD |

`.dictionary` 二进制格式是 Apple 私有的，**没有第三方工具能直接写**，必须经过官方工具链。
